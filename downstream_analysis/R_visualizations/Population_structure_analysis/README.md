# Population structure analysis (DAPC)

This folder contains R scripts for Discriminant Analysis of Principal
Components (DAPC) used to study population structure in Candida auris.

## Input
- VCF file (not included in GitHub)
- population map file

## Output
- DAPC scatter plots
- membership barplots
- summary tables

## Usage
Run from this directory:

Rscript dapc_analysis.R
