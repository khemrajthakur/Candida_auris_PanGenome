# Phylogenetic analysis – Candida auris

This folder contains R scripts for visualizing the phylogenetic
relationships among Candida auris isolates using a rooted species tree.

## Input
- SpeciesTree_rooted.txt (Newick format, not included in GitHub)

## Output
- Circular phylogenetic tree with clade annotations

## Usage
Run from this directory:

Rscript phylogenetic_tree.R
